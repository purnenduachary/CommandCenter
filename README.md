# Mac's Command Center — Latverian Protocol

A responsive, offline-friendly personal dashboard with a Doctor Doom-inspired visual direction: gunmetal surfaces, oxidized emerald energy, antique-gold detailing, and an original animated portal sigil inspired by the green mark left after Doom collects Banner in *Avengers: Endgame Encore*.

## Run it

Keep `index.html`, `style.css`, and `script.js` in the same folder. Open `index.html` in a browser. No build tools or server are required.

## Progress storage

The current version stores checklist and interview-question data in the browser's `localStorage`. Data stays in that browser profile and does not automatically sync between devices. Clearing browser site data can erase it.

## Motion and accessibility

The sigil, subtle scan effect, ambient glow, and card entrance animations respect the operating system's `prefers-reduced-motion` setting.

## Deploy

Upload the contents of this folder to the root of a GitHub repository and enable GitHub Pages from `main` / `/(root)`.
